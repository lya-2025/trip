# Trip

**Trip · 中国十大热门旅行景点攻略** — 一个纯静态旅行攻略网站，展示中国十大热门景点的详细攻略信息，帮助用户快速了解目的地并规划行程。

## Getting Started

无需构建工具、无需后端，浏览器直接打开即可运行。推荐用本地服务器预览以支持 `fetch` 数据加载：

```bash
python -m http.server 8123
```

然后访问 http://127.0.0.1:8123/index.html

> 直接以 `file://` 打开也可使用：首页数据加载失败时自动回退到 `js/main.js` 内联数据，功能不受影响。

## 功能特性

- **景点卡片网格**：首页展示 10 个景点，含名称、城市、简介、标签与耗时/门票
- **实时搜索**：按景点名称、城市或关键词过滤（带 200ms 防抖）
- **分类筛选**：自然风光 / 历史人文 一键切换
- **详情页**：每处景点含图片轮播、8 个攻略区块（简介/交通/门票/路线/最佳时间/美食/住宿/注意事项）、6 张实用信息卡片
- **页面内导航**：攻略区块锚点跳转 + 滚动联动高亮
- **景点间导航**：底部上一个/下一个快捷入口，环形循环
- **响应式布局**：桌面自适应多列、平板/手机自适应单列，移动端汉堡菜单
- **无障碍**：内联 SVG 图标、`:focus-visible` 焦点环、`prefers-reduced-motion` 支持

## Project Structure

```
index.html              首页（导航栏 / Hero / 搜索筛选 / 卡片网格 / 页脚）
spots/                  10 个景点详情页
css/style.css           公共样式（深色玻璃拟态设计系统）
js/main.js              公共脚本（数据加载 / 搜索 / 筛选 / 轮播 / 导航 / 返回顶部）
data/spots.json         景点结构化数据（供首页 fetch 加载）
assets/images/          景点图片（Wikimedia Commons，CC BY-SA，30 张）
ATTRIBUTION.md          图片版权与致谢
旅行攻略网站需求.md      需求文档
```
